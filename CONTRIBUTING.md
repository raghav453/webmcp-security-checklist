# Contributing

Improve a reproducible developer task: a missing edge case, clearer evidence, a corrected API revision, or a well-explained resource. Open an issue describing the problem and relevant source; submit a small pull request with the change, why it helps, and validation performed. No promotional-only links or copied articles. Disclose affiliation when recommending your own resource.

For technical changes, cite a dated primary source and distinguish draft, browser implementation, polyfill, and manual UI behavior. For checklist changes, include the failure it detects and the evidence that closes it. Do not include personal data, production logs, tokens, or private application code. Respectful, specific technical feedback is expected.

Original contributions use the repository's MIT license; preserve third-party licensing and attribution. Maintainers review changes before merging. See [MAINTENANCE.md](MAINTENANCE.md) for the update process.
