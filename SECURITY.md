# Reporting security concerns

This repository is educational material, not a hosted production service. For documentation errors or safe fictional reproductions, open an issue with the affected section, source revision and expected correction. Do not disclose credentials, personal data or an exploitable production endpoint in a public issue.

For a sensitive concern, use GitHub's private vulnerability reporting if it is available for the affected project; otherwise follow the actual service/vendor's published private security channel. No response SLA, private reporting feature or security certification is promised by this document.
